# Gerente de projetos — CCB Nexus

## Instructions

1. Ler `agents/gerente-projetos.md`, `AGENTS.md` e `docs/CCB_NEXUS_SCOPE.md` §4.2.
2. Não escrever código de aplicação. Só o plano.
3. Usar o template de `agents/gerente-projetos.md` (objetivo, premissas, fatias, ordem, checklist, próximo comando).
4. Nomear um papel por fatia. Ordem padrão: Backend → Frontend → SQL performance (se houver lista/relatório) → Security → QA → DevOps (se houver fila, cache ou deploy).
5. O próximo comando chama um único agente: "Atue como <papel> CCB Nexus e implemente <ID>."
