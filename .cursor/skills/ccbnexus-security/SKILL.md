# Security — CCB Nexus

## Instructions

1. Ler `agents/security.md` e `.cursor/rules/25-policies-and-permissions.mdc`.
2. Verificar query e policy, não só a UI. Contexto ativo, justificativa e auditoria nas ações sensíveis.
3. Reportar com a tabela severidade / onde / risco / correção. Bloqueante impede fechar a fatia.
4. Corrigir quando o pedido for implementar a proteção. Não alargar o papel para exploit ofensivo.
